## B004.0 训练出口修复（先完成）

`check_training_export`/`export_training_records` 现在共享以下拒绝条件：空记录、
空 token/prompt/response、零生成 token、schema 版本不符、数组长度/类型/有限性
不符、sampling 合同被改、缺失或未完成 outcome、UNKNOWN/NOT_RUN/INFRA_ERROR、
缺 verifier 事实、重复 rollout、组数量不完整和 task/policy/tokenizer/template/
`harness` 身份混用。直接传入已编译 dict 也会重新校验这些条件；`context_id` 只在
单条 trajectory 内约束 append-only context，独立 rollout 在同一组可以不同。
`sampling_config` 仅允许已列明字段；presence/frequency penalty 非零、非空
logit_bias 和未知 sampler 字段会被拒绝。

`src/mimo_rl/reward.py` 定义项目自己的 `VerifierOutcome`，不冒充官方类型：

* `rc=0 + resolved=true + raw_reward=1.0` → 合法 `PASS`；
* `rc!=0 + resolved=false + raw_reward=0.0` → 合法 `TEST_FAIL`；
* `reward/testbed_corrupted`、`transport_error=true` 或官方 `agent_status=InfraError`
  → `INFRA_ERROR`，reward 为 null；
* 缺 verifier returncode/resolved、字段矛盾、未知错误、NaN/Inf/bool → `UNKNOWN`
  或结构校验错误；不会把 reward=0 猜成模型失败。

独立反例保留了合法 PASS、TEST_FAIL、synthetic 金标准和旧回归；测试覆盖空
JSON/JSONL、空/pending outcome、基础设施类别、采样篡改、不同 context 合法组、
身份混用、组不完整、数组错误和直接导出入口绕过。

## B004.2 runtime_preflight

新增标准库脚本 [`scripts/preflight_runtime.py`](../../scripts/preflight_runtime.py)。
它使用显式解释器的受控 `-I -c` 子进程检查版本、实际 package import location/
version；只读调用 `docker info` 检查 daemon/权限/平台，不安装、不启动、不拉取、
不创建容器，也不读取完整环境变量或凭据。

当前开发机实测：Python `3.9.6`，固定 mimoagent 要求 `3.12.*`；`mimoagent`、
`slime`、`uni_agent`、`verl` 均未发现；固定 commit 的安装包 revision 不可追溯；
Docker CLI 不在 PATH，daemon 检查因此 `NOT_RUN`。因此总状态为 `BLOCKED`，不是
`READY`。

命令和退出码：

```text
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python scripts/preflight_runtime.py \
  --runtime-python .venv/bin/python
```

退出码：`1`。结构化 blocker codes：
`python_version_mismatch`、`missing_package`、`mimoagent_revision_unverified`、
`missing_docker_cli`（daemon 为 `NOT_RUN`）。本轮不擅自安装 Python 3.12、上游
包或 Docker。

## B004.3 官方环境薄适配和无模型 smoke

[`scripts/smoke_official_code.py`](../../scripts/smoke_official_code.py)：
