## B003.1–B003.5 实现

固定源码的文件、符号、调用链、长度/mask/logprob 语义追加在
[`docs/UPSTREAM_CONTRACT.md`](../../docs/UPSTREAM_CONTRACT.md)。读取的版本为：

| 用途 | 固定 commit | 范围 |
|---|---|---|
| slime | `89bfada990a00663846e0ac804de1454685ceed3` | `source_read` |
| MiMo-Agent | `467f0a19016f0ac4d63b8d17a1f0da9ba07f232c` | `source_read` |
| uni-agent | `c63e0b01c375ebede95e01fe92bc367df24e5bf3` | `source_read` |
| official recipe / submodule | `a2ad9f6160b03ff2d47e59832bfb6b289f37c917` / `e7f889574b8301cc0f0fc1d57c6d67f31ffeb689` | `source_read` |

`src/mimo_rl/trajectory.py` 保存依赖无关的 `GenerationEvent`、`ToolEvent` 和
`Trajectory` 原始调用记录；不会导入 slime、实例化假的 `Sample`、执行
`train()`、重新 tokenize 历史文本或计算 reward。编译器只接受同一 context 的
append-only 输入前缀。新增的工具/模板/观察 token 使用 `mask=0, logprob=0.0`；
模型生成 token 使用 `mask=1`，且必须携带原始真实概率，绝不以零填充缺失概率。
采样合同固定为 temperature/top-p/repetition penalty 为 1、top-k 为 0、
full-vocabulary probability。

脱敏离线入口是 [`scripts/inspect_trajectory.py`](../../scripts/inspect_trajectory.py)：
它只读 JSON/JSONL，本地编译并输出数量、来源、生成 token 数、错误码和
`parameter_update=false`，不输出完整原始轨迹。`--export-training` 只在 source
为 captured、存在 `capture_evidence=engine_raw`、数组合同完整、身份一致、
outcome 完整、无 `INFRA_ERROR` 且 group 数量完整时标记 future export eligible；
synthetic、缺概率、类型错误、前缀变化、身份混用、不完整 group 和 text-only
轨迹都会被拒绝。
